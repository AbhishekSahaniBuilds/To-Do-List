About To Do List

A fast, clean, and private task manager.

Privacy & Simplicity First

To Do List was built to make tracking your daily tasks straightforward and hassle-free. Registration takes seconds with zero tracking or unnecessary personal info required—just a simple username and password to keep your tasks secure.

Every task you add is saved safely to a database associated with your account, so your list is always waiting for you whenever you log back in.

Under the Hood

This full-stack application is hand-coded using a robust modern stack:

Frontend HTML5 CSS3 JavaScript
Backend Python FastAPI MongoDB

The frontend uses clean HTML and CSS, while the backend relies on high-speed Python with FastAPI communicating smoothly with MongoDB.
